## Overview

**Waste 2 Value** is a sustainability-focused material research project exploring the recycling and reuse of discarded construction materials, specifically waste bricks.

The project investigates how discarded bricks can be processed, combined with other components, and transformed into a new usable brick. It aims to demonstrate the potential of material recovery while raising awareness about sustainable construction practices and the value of resources that would otherwise be considered waste.

Alongside the practical material research, this repository contains a dedicated website documenting the project's development, experimental stages, visual evidence, and contributors.

## Project Objectives

- Explore innovative approaches to construction waste recycling.
- Investigate the potential of reusing discarded bricks as raw material.
- Document the material transformation process from preparation to final testing.
- Promote sustainable thinking and resource efficiency in construction.
- Present the research process through an accessible digital platform.

## Material Transformation Process

The project documents six main stages of the material transformation journey:

| Stage | Process | Description |
|---|---|---|
| 01 | Preparing | Initial preparation and processing of discarded bricks. |
| 02 | Dividing | Crushing, sieving, and separating the material into particle-size fractions. |
| 03 | Mixing | Measuring and preparing the individual components. |
| 04 | Integrating | Combining the recycled material with the other components and preparing the mixture. |
| 05 | Drying | Drying the moulded material under controlled conditions. |
| 06 | Testing | Examining and documenting the resulting recycled brick. |

Each stage is supported by photographs and visual documentation to provide insight into the experimental workflow.

## Website Features

The project website serves as a digital documentation platform, featuring:

- **Project Introduction:** Background, objectives, and the concept behind Waste 2 Value.
- **Interactive Process Gallery:** A visual presentation of the six material transformation stages.
- **Photo Documentation:** Organized photographs with descriptions explaining individual activities.
- **Project Film:** Video documentation showcasing the project and its development.
- **Testing Documentation:** Visual material from the final testing stage.
- **Project Contributors:** Information about participating students and academic contributors.
- **Responsive Design:** An accessible interface designed for different screen sizes.

## Getting Started

The website is a static project and does not require installing dependencies or configuring a backend.

### 1. Clone the repository

```bash
git clone https://github.com/nor1t/Waste2Value.git
```

### 2. Navigate to the project directory

```bash
cd Waste2Value
```

### 3. Run the website

Open `index.html` directly in your browser, or start a local development server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Project Collaboration

Waste 2 Value was developed as part of an international academic collaboration involving students and professors from different educational institutions.

The project was led by **GIZ (Deutsche Gesellschaft für Internationale Zusammenarbeit)** in collaboration with the **University Ss. Cyril and Methodius in Skopje, Faculty of Technology and Metallurgy**.

The collaboration brought together participants from different academic backgrounds to explore sustainable material reuse through research, experimentation, and documentation.
